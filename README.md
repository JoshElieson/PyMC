# PyMC
**Team Metapods: Josh Elieson & Nick Armstrong**
Track 3: Teach Daimon a job it can't do yet.


**Concept Overview**
Daimon can make basic presentation slides, using some user input.
We want to improve this process.

**What we Built**
slide-expert.md is a skill that improves Daimon’s ability to make presentations:
1. Use an input template, extracting relevant details
2. Present slides for user review, allowing easy edit to layout, font, images, & theme
3. Publish slides in .pptx or .pdf formats, all within Discord

**Workflow**  
User:     Request slides  
Daimon:   Asks for a template  
User:     Upload any previous slides/template  
Daimon:   Extracts details, makes slides, sends for review  
User:     Review sides, easy edit to an details, hit publish  
Daimon:   Published slides to user for download
